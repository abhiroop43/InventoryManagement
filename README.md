<p id="description">A simple inventory management system built using Microsoft Stack and free from the JavaScript plague 🤮</p>

<h2>🧐 Features</h2>

Here're some of the project's best features:

- Manage Inventory Items (in progress)
- Create Products from available inventories (planned)
- Procure new inventories (planned)
- Role-based Access control (planned)
- Approval process for procurement (planned)
- In-app and email notifications (planned)
- DDD and Clean Architecture
- CQRS Pattern
- No JavaScript Frameworks just pure HTML and CSS
- Bootstrap for theming to avoid any CSS utility class drama 🎭

<h2>🛠️ Installation Steps:</h2>

<p>1. Clone or download the repository</p>

```
git clone https://github.com/abhiroop43/InventoryManagement.git
```

<p>2. Navigate to the solution folder</p>

```
cd InventoryManagement
```

<p>3. Restore nuget packages</p>

```
dotnet restore
```

<p>4. Run the solution</p>

```
dotnet run
```

<p>5. Navigate to the URL https://localhost:7215/</p>
